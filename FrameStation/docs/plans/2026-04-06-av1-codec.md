# AV1 Codec Support Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add AV1_MAIN8 and AV1_MAIN10 codec options to the stream quality settings so users can choose AV1 decoding when the host server supports it.

**Architecture:** `MoonBridge.VIDEO_FORMAT_AV1_MAIN8` and `VIDEO_FORMAT_AV1_MAIN10` constants already exist in moonlight-core. We add `AV1_MAIN8` and `AV1_MAIN10` to the `VideoCodec` enum, update the two `when` blocks in `MoonlightStreamManager` that map codec → format flags, guard AV1 with `Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q` (API 29), and the `SettingsDialog` codec dropdown automatically picks up the new entries via `VideoCodec.entries`.

**Tech Stack:** Kotlin, `MoonBridge.VIDEO_FORMAT_AV1_MAIN8/MAIN10`, `PreferenceConfiguration.FormatOption.FORCE_AV1`, `Build.VERSION_CODES.Q`

## Task 2: Update `MoonlightStreamManager` codec → format mapping

**Files:**
- Modify: `app/src/main/java/com/xrworkspace/app/streaming/MoonlightStreamManager.kt`

**Step 1: Add import for `Build`**

Check if `android.os.Build` is already imported. If not, add:
```kotlin
import android.os.Build
```

**Step 2: Update video format mask block**

Find:
```kotlin
                    // Map codec preference to Moonlight video format flags
                    val videoFormats = when (streamCodec) {
                        VideoCodec.AUTO -> MoonBridge.VIDEO_FORMAT_H264 or MoonBridge.VIDEO_FORMAT_H265
                        VideoCodec.H264 -> MoonBridge.VIDEO_FORMAT_H264
                        VideoCodec.H265 -> MoonBridge.VIDEO_FORMAT_H265
                    }
```
Replace with:
```kotlin
                    // Map codec preference to Moonlight video format flags.
                    // AV1 requires API 29 (Android 10) for hardware decode support.
                    val av1Supported = Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q
                    val videoFormats = when (streamCodec) {
                        VideoCodec.AUTO -> {
                            var mask = MoonBridge.VIDEO_FORMAT_H264 or MoonBridge.VIDEO_FORMAT_H265
                            if (av1Supported) mask = mask or MoonBridge.VIDEO_FORMAT_AV1_MAIN8
                            mask
                        }
                        VideoCodec.H264 -> MoonBridge.VIDEO_FORMAT_H264
                        VideoCodec.H265 -> MoonBridge.VIDEO_FORMAT_H265
                        VideoCodec.AV1_MAIN8 -> if (av1Supported) MoonBridge.VIDEO_FORMAT_AV1_MAIN8
                            else MoonBridge.VIDEO_FORMAT_H265 // graceful fallback
                        VideoCodec.AV1_MAIN10 -> if (av1Supported) MoonBridge.VIDEO_FORMAT_AV1_MAIN10
                            else MoonBridge.VIDEO_FORMAT_H265_MAIN10 // graceful fallback
                    }
```
